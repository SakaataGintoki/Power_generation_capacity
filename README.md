# Power_generation_capacity
Professional Excel dashboard showcasing analytical and reporting skills.
# Description
This project presents an interactive Excel dashboard analyzing power generation capacity across multiple energy sources, including Coal, Gas, Diesel, Nuclear, Renewable (RES), Hydro, and Lignite.
The dashboard provides region-wise, sector-wise, state-wise, and year-wise insights, helping understand capacity distribution, growth trends, and energy mix patterns.

Built using advanced Excel features such as Pivot Tables, slicers, charts, and calculated metrics, this project demonstrates strong skills in data analysis, visualization, and business reporting.
